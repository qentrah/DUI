# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting feature for the `qentrah/DUI` repository:

1. Open the repository's **Security** tab.
2. Select **Advisories**.
3. Select **Report a vulnerability**.

Include the affected component or registry item, reproduction steps, impact, and any suggested mitigation. The maintainers will acknowledge the report, investigate it, and coordinate disclosure when a fix is available.

## Supported versions

Security fixes are applied to the latest release and the default branch. Consumers should pin a reviewed release or commit when reproducible installations are required.
