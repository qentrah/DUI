# Qentrah Skills

Public, portable skills maintained by Qentrah. Each repository contains the canonical `SKILL.md`, its purpose, ownership, and documentation.

Install a skill with `npx @qentrah/skills add &lt;skill-name&gt;`.

| Skill | Goal | Repository |
| --- | --- | --- |
| Design Critique | Review interfaces for accessibility and product consistency. | [qentrah/skill-design-critique](https://github.com/qentrah/skill-design-critique) |
| UI Implementation | Build responsive, system-aligned React interfaces. | [qentrah/skill-ui-implementation](https://github.com/qentrah/skill-ui-implementation) |
| Content Design | Create concise, translation-ready product copy. | [qentrah/skill-content-design](https://github.com/qentrah/skill-content-design) |
| Code Review | Find correctness, maintainability, and production risks. | [qentrah/skill-code-review](https://github.com/qentrah/skill-code-review) |
| Release Readiness | Validate metadata, routing, performance, and deployment. | [qentrah/skill-release-readiness](https://github.com/qentrah/skill-release-readiness) |
| Repository Guide | Explain where source, registry, and documentation belong. | [qentrah/skill-repository-guide](https://github.com/qentrah/skill-repository-guide) |
| Architecture Guardian | Protect Qentrah data models, domain interfaces, and backend ownership. | [qentrah/skill-architecture-guardian](https://github.com/qentrah/skill-architecture-guardian) |

All seven skills are created and maintained by [Ahmed Mansour](https://github.com/Up-to-code) for [Qentrah](https://github.com/qentrah).
